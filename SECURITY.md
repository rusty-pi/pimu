# Security

pimu is a test tool that runs firmware images you give it inside a model. It
handles no secrets of its own and listens on no port unless you ask for
`--net` or `--tftp`/`--http`.

Report a vulnerability, or material in this repository that should not be
public, privately through GitHub's "Report a vulnerability" on the Security
tab, or by email to the maintainer listed on the commit log. Please do not open
a public issue for either.
